    uint8_t ADR_ =0x28

    Begin communications with the T9602 sensor.

    Parameters:

    • ADR_ I2C address. Defaults to 0x28. This library cannot change this, but this option exists in case you make this change elsewhere.

    Return: true if the sensor acknowledges its address on the bus.

    function updateMeasurements

    bool updateMeasurements()

    Measure relative humidity [%] and temperature [degrees C].

    Return: true if every reading was valid. false if any timed out (stale or no data, sensor in command mode, or no sensor); the stored values are NW_ERROR (-9999) when none was valid.

    Takes setReadings(n) readings (default one). Each sends a measurement request, then fetches data until the sensor’s status bits report a valid (not yet fetched) measurement, or until T9602_TIMEOUT_MS passes; readings are therefore independent measurement cycles. The getters return the mean of the readings taken.

    function getStatus

    uint8_t getStatus()

    Status bits from the last data fetch.

    Return: 0: valid data; 1: stale data (already fetched since the last measurement cycle); 2: sensor in command mode (start-up); 3: no data (no sensor on the bus).

    function getString

    String getString(
    bool takeNewReadings =false
)

    The most important function for the user! Returns all data as a comma-separated string: “RH,T,”.

    Parameters:

    • takeNewReadings if true run updateMeasurements before returning values. Otherwise, just return values.

    This string is: “RELATIVE_HUMIDITY,TEMPERATURE,”. It is written with the code: return String(RH) + “,” + String(Temp) + “,”
